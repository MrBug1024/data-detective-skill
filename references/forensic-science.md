# 刑侦模式：物证、同一认定与证据评价

处理现场、鞋印、指纹、DNA、微量物证或鉴定结论时读本文件；竞争假说与调查排序见 [investigation-methods.md](investigation-methods.md)。本参考给 Agent 提供推理约束与送检问题，不把语言模型输出当作鉴定。

## 先定义要回答的命题

把每条推断写成可审查记录：`命题 / 层级 / 引用的证据 ID / 可替代解释 / 依赖的假设 / 如何验证 / 当前状态`。区分四层：

| 层级 | 示例 | 不能跳过的缺口 |
|---|---|---|
| 观察 | 照片中有一处疑似鞋底纹印 | 比例尺、原图、变形、是否为鞋印 |
| 来源 | 该印痕是否由待比鞋形成 | 鞋型共有特征与随机获得特征、印痕质量、比较方法 |
| 活动 | 谁在何时穿鞋到过该处 | 鞋的借用、历史合法接触、二次转移、形成时间 |
| 案件责任 | 谁实施了被调查行为 | 其他证据及适用程序，不能由同源结论自动推出 |

ENFSI 的命题层级与成对评价框架适用于**法庭科学评价报告**，不是一套已验证的自动破案算法。明确区分来源命题、活动命题和案件责任；案情不足时只报告调查线索及缺口。[ENFSI Evaluative Reporting, approved v3.0, §§1–3、Guidance Note 2](https://enfsi.eu/wp-content/uploads/2016/09/m1_guideline.pdf)

## 洛卡德、转移与保管链

洛卡德原理提示寻找接触产生的物质交换，但发现痕迹还需解释转移、留存、检出条件；未检出也不能自动证明未接触。最小记录：证物 ID、发现位置、日期时间、采集者、现场照片/测量、包装封签、每次移交及处理。[SWGMAT Trace Evidence Recovery Guidelines, §§2–4，1998；NIST 托管历史指南](https://www.nist.gov/system/files/documents/2016/09/22/trace_evidence_recovery_guidelines.pdf)

针对本案逐一比较：直接接触、经中介物二次转移、日常背景、采集或实验室污染。记录人员与器材跨区接触、已知污染、阴性/环境对照及包装状态。DNA 检出不等于案发时直接接触；不同解释需要不同的活动层级资料。[英国 Forensic Science Regulator，Contamination controls: scene of crime，2023，§§1、4、6](https://www.gov.uk/government/publications/crime-scene-dna-anti-contamination-guidance/contamination-controls-scene-of-crime-accessible)

Agent 遇到保管链断点时，应说明“该缺口影响哪些命题、补何种记录可解决”，不要把缺口直接宣布为污染已发生或证据必然无效。现场任务优先建议由具备相应资质的人员保护、记录和采集；不要为了验证模型的猜想先行移动、清洗或破坏痕迹。

## 鞋印与身体特征：可做什么

先分清裸足印、鞋底印、照片还是文字描述。记录完整性、实际长度和宽度及单位、比例尺是否与印痕同平面、基质、深度、坡度、行进方向、重叠关系及采集前人员出入。没有可靠测量时，优先补原图和现场测量，不从视觉“估厘米”。

| 材料 | 合理下一步 | 当前不能支持 |
|---|---|---|
| 单枚残缺鞋底印 | 保全全景/中景/带比例尺细节；比较花纹、尺寸、磨损和可见损伤 | 精确身高、年龄、性别、体重、身份 |
| 高质量全鞋底印与待比鞋 | 经适用方法制作比较样本，由检验人员评价共有特征和随机获得特征 | 一致花纹就认定同一只鞋；同鞋就认定穿鞋人 |
| 可测裸足印和经过验证的适配研究模型 | 核对研究人群、印痕类型、测量定义与外部验证，再决定是否估计身高 | 把裸足公式套到鞋底外长；把相关系数当作个体准确率 |
| 连续足迹 | 描述步长/步宽、路径和变异，列出跑动、负重、基质等解释 | 仅凭深浅判体重；仅凭步态判职业、人格或犯罪动机 |

鞋印量化研究主要比较鞋底设计、尺寸、磨损、随机获得特征，并需要相关的同源/异源样本数据库及误差评价；算法相似分不是有罪概率。[Venkatasubramanian et al., 2021，NIST 原始研究](https://www.nist.gov/publications/quantitative-evaluation-footwear-evidence-initial-workflow-end-end-system)

裸足测量研究可建立特定人群回归模型，例如 100 名印度年轻成人的静态足印研究；这不验证任意现场鞋印的跨人群推算。要给个体身高估计，必须取得适配模型、测量输入、模型误差与**个体预测区间**，同时报告外推限制。无这些条件就写“现有材料无法可靠估计”，不得编造“脚印长×固定倍数”的通用公式。年龄、性别、体重不能由本案单枚鞋印可靠确定。[Kanchan et al., 2013，原始研究摘要与 DOI](https://pubmed.ncbi.nlm.nih.gov/24252397/)

## LR 与贝叶斯：数字使用条件

先明确互相竞争且处于同一层级的 `H1`、`H2` 和背景 `I`：

`LR = P(E | H1, I) / P(E | H2, I)`

`后验赔率 = 先验赔率 × LR`

LR 比较的是证据在两个命题下的相对可能性。它不是命题为真的概率、误判率或“嫌疑人有罪的百分比”；`P(E|H)` 不能倒置成 `P(H|E)`。先验缺失时不能偷偷使用 50:50，更不能把检索分数代入。[Royal Statistical Society，Practitioner Guide 1，§§2.29、3](https://rss.org.uk/RSS/media/News-and-publications/Publications/Reports%20and%20guides/rss-fundamentals-probability-statistical-evidence.pdf)

本 Skill 的操作规则：

1. 仅在有可追溯的概率数据或经过验证的专家模型时计算数字，保存输入、出处、适用范围和敏感性分析。普通案件描述没有这些资料时，进行定性比较并将 LR 留空。
2. 同一录像的两张截帧、转述同一证人的三篇报道、同一鞋印的长度与鞋码属于潜在依赖，不能当作独立证据相乘。无法建立联合模型时，按来源组讨论或分别展示。
3. “未发现”只有在相应假说预期应出现、现场确实检查、检测有足够灵敏度且留存条件合适时，才可能产生反证意义；把检查覆盖范围写出来。
4. 结论分别报告证据质量、命题支持、尚存替代解释；不要将资料数量或启发式分数包装成校准概率。对来源同一性有支持时，也保留活动层级的未决问题。

## 输出前复核

逐条检查报告是否把“相容”写成“唯一”、把“鞋”写成“人”、把“在场”写成“实施行为”、把“未检出”写成“不存在”、把“检索相关”写成“真实”。有任一跳跃，降回证据能支持的层级，并给出能填补该缺口的下一项检验。
