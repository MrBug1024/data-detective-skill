# 数据溯源多场景验证

评测围绕同一条数据溯源流程，覆盖结构化连接、文档证据、实体标识、字段映射与计算核验。

- `lineage/`：电商、物流、财务、实验、制造等原始场景与独立预期。含跨命名空间碰撞、缺范围、晚到冲突、多工作表配置、互补缺键等反例，报告TP/FP/FN及未决项。
- `data_entity/`：沿用跨格式原始夹具，验证CSV、SQL、XLSX、JSON、DOCX、PDF、OCR sidecar的原始定位与显式计算。目录名为历史名称，不表示执行分成不同业务流程。
- `tests/`（仓库根目录）：离线回归、完整性、缓存变化、预算、失败恢复、机器状态与调查墙引用检查。

运行使用本地合成材料，不需要外部模型服务。评分器与原始输入分开；独立Agent前向测试只接收原始材料、实际技能与必要工具，不提供预期或已有报告。目录叫private不等于权限隔离，真正盲测需要隔离可读范围。

新算法先在不透露答案的原始场景上运行，记录失败，再修复并重新验证已有场景与新增反例。测试不能只断言实现内部字段；需要核对原始文件中的实际记录、字段和引用。

性能区分空应用缓存、索引准备、首次键查询、异键/异列查询和重复查询；同时报告结果等价性与磁盘占用。真实业务数据仅在用户授权的本地路径进行验收，不随精简包发布。
